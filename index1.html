Program 4 — Simple Calculator

Quick memory: Remember: operator button submits the form; switch selects +, -, * or /.
<html>
<?php
if (isset($_POST["operator"])) {
    $first_num  = $_POST["first_num"];
    $second_num = $_POST["second_num"];
    $operator   = $_POST["operator"];
    $result     = "";

    if (is_numeric($first_num) && is_numeric($second_num)) {
        switch ($operator) {
            case "+":
                $result = $first_num + $second_num;
                break;

            case "-":
                $result = $first_num - $second_num;
                break;

            case "*":
                $result = $first_num * $second_num;
                break;

            case "/":
                $result = $first_num / $second_num;

}

Armstrong Number

Quick memory: Remember: % 10 gets last digit; divide by 10 removes last digit; add digit³.
<html>
<body>
<form method="POST">
<table border="1">
<tr>
    <td>Enter Number:</td>
    <td><input type="number" name="number"></td>
</tr>
<tr>
    <td></td>
    <td>
        <input type="submit" value="Submit" name="Submit">
    </td>
</tr>
<?php
if (isset($_POST['number']))
{
    $a = $_POST['number'];
    $number = $a;
    $sum = 0;

    while ($number != 0)
    {
        $r = $number % 10;
        $sum = $sum + ($r * $r * $r);
        $number = (int)($number / 10);
    }

    if ($a == $sum)
    {
        echo "$a is an Amstrong Number";
    }
    else
    {
        echo "$a is not an Amstrong Number";
    }
}
?>
</table>
</form>
